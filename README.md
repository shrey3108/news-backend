# Real-Time News Backend

## Tech Stack
- Node.js
- Express.js
- MongoDB
- Socket.io

## Setup
1. Clone repository
2. `npm install`
3. Create .env file
4. `npm start`

## Environment Variables
- `MONGO_URI`: MongoDB connection string
- `PORT`: Server port (default 5000)

## Features
- Real-time news updates
- WebSocket integration
- MongoDB aggregation
- Swagger documentation
